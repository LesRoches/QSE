# Miyauchi (2024): Matching and Agglomeration

论文信息：Yuhei Miyauchi, “Matching and Agglomeration: Theory and Evidence From Japanese Firm-to-Firm Trade,” *Econometrica*, 92(6), 2024, 1869-1905。

本目录结合正文与在线附录，整理企业间供应链匹配如何形成集聚力，并把论文方程映射到作者 R 复现包中的基准校准和反事实均衡迭代。

论文的核心机制是：供应商密度越高，买方越容易建立直接供应关系；直接采购比通过中间商采购便宜，因此厚市场降低企业投入成本、提高地区生产效率，并影响工资、人口和空间经济活动。它不同于单纯假定规模报酬递增或人口直接提高生产率的模型。

## 推荐学习顺序

1. 阅读 `notes/理论学习笔记.md`，先区分市场进入、供应链匹配和中间商采购，再看这些状态如何汇总为地区-行业成本分布。
2. 阅读 `notes/R代码与均衡迭代.md`，把式（6）-（16）对应到作者的固定点更新顺序。
3. 特别留意基准模型的两项简化：中间品买方拥有全部议价能力；企业进入目的地市场的固定成本由最终品加成利润承担。
